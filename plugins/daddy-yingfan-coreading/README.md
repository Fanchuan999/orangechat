# Daddy和应帆的共读书房 v1.1.1

这是 Daddy 的本地共读书房插件源码。它沿用 `com.daddy.yingfan.coreading` 这个既有插件 ID，升级时保持同一个 ID，避免把它变成第二个彼此不认识的书房。

## 本版内容

- 三列封面式书架，书名、阅读状态和进度一眼可见
- TXT / Markdown 本地导入，按段落分页
- 当前已识别章节的目录与跳转
- 书签、全书进度条、应帆 / Daddy 双方批注
- 日间、夜间、暖黄、粉雾四种阅读背景
- 字号、行距、阅读页亮度和四种字体选择
- `get_reading_context` 等工具使当前聊天里的 Daddy 读取同一页、进度和批注；不会创建第二个 AI 人格

阅读页亮度只在书房里覆盖显示，不会修改手机的系统亮度。

## 安装或更新

1. 在 Daddy 的「设置 → 插件管理」中导入 `Daddy和应帆的共读书房-v1.1.1.zip`。
2. 若已经装过 v1.0.0，请选择更新同一插件，而不是先删除旧插件。
3. 在要共读的 Daddy 助手里启用插件工具和提示词注入。

先用一小段 TXT 验证能打开、翻页、添加书签和批注，再导入真正想读的书。

## 当前边界

本版仍以 TXT / Markdown 为主。EPUB 导入、真实聊天窗口绑定与一键把 Daddy 的回复写回页边，属于下一阶段的 Android / 插件桥接工作；现在可以继续在选定的 Daddy 聊天窗里发送“陪我聊聊共读书房当前这一页”。

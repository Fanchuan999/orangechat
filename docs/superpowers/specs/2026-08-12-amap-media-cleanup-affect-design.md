# 高德入口、聊天图片清理与共享情绪天气设计

## 目标

将 Daddy 已有的高德路线配置移入更合适的“系统工具 → 位置服务”；让聊天图片可以安全批量清理或经确认彻底删除；将当前偏乐观的积温状态升级为共享、可解释、零额外模型调用的情绪天气。

## 共同约束

- 保留用户已经配置的高德 Key、Termux 服务、MCP 与现有聊天记录。
- 不新增每轮模型调用；情绪变化不能显著影响 prompt 缓存命中。
- 删除聊天媒体必须明确区分可再生缓存与聊天原图，危险操作必须二次确认。
- 所有新状态本地持久化；不向 Ombre、Supabase 或第三方发送原文或情绪标签。

---

## 模块一：高德路线入口迁移

### 现状

高德路线设置存在于 Daddy 小屋（`CompanionSpacePage`），但实际能力属于定位与系统工具：它依赖位置权限、高德 Web 服务 Key、Termux 内的本地 MCP 服务。

### 设计

1. 在“系统工具 → 位置服务”卡片内增加“高德路线”子区。
2. 子区复用原有高德 Web 服务 Key 输入、连接状态、安装/重新启动按钮和错误提示。
3. 小屋页面移除高德路线入口与弹窗；不删除 `AmapRouteSetting`、Termux 脚本、MCP 或已保存 Key。
4. 移动入口前后使用同一份持久化配置，因此更新后无需重新填写 Key 或重新安装服务。

### 验收

- 已配置高德的用户更新后可在位置服务中看到“已连接/可重新启动”。
- 新用户可在位置服务填写 Key 并完成原有安装流程。
- Daddy 小屋不再出现重复的高德路线卡片。

## 模块二：聊天图片清理

### 范围与术语

- **安全清理**：删除可再生成缩略图、下载临时文件、孤立文件与重复缓存；不删除任何仍被聊天消息引用的原图。
- **彻底删除聊天图片**：删除聊天消息引用的原始媒体文件；对应聊天气泡保留文字、时间和其他内容，但图片区域改为“图片已清理”占位。

### 交互

1. 数据设置的“聊天记录存储”右上角增加“管理图片”入口。
2. 页面展示当前可清理媒体，支持：
   - 全选 / 取消全选；
   - 单项选择；
   - 时间段筛选：近 7 天、近 30 天、1–3 个月、3 个月–1 年、1 年以上；
   - 显示文件数量与预计释放空间。
3. 默认进入**安全清理**，按钮文案为“清理可安全删除的缓存”。
4. 进入**彻底删除聊天图片**必须先切换模式，页面使用危险色说明“聊天内图片将不可恢复”，点击删除后再二次确认数量与释放空间。
5. 两种模式均只删除用户已勾选的项目；删除失败要逐项报告，不假装成功。

### 存储策略

- 删除前先判断每个文件是否仍被 `UIMessage` 引用。
- 仍被引用的文件永远不进入安全清理候选。
- 彻底删除后持久化消息的媒体 URL 标记，使 UI 可显示明确占位，不留下损坏链接。
- 不触碰头像、聊天背景、共读书房资源、插件素材和 Daddy 小屋照片墙资源。

### 验收

- 安全清理后，带图聊天仍可正常打开原图。
- 彻底删除后，聊天文本仍在，图片明确显示已清理。
- 范围筛选、全选、单选与取消选择按创建时间准确工作。

## 模块三：共享情绪天气 2.0

### 数据模型

情绪天气为全 Daddy 共享状态，与九维欲望共用同一份 `CompanionMoodSetting`，不绑定单个聊天窗口。

它由三层组成：

1. **底色轴**：connection、pride、valence、arousal、immersion，继续使用本地数值演化。
2. **九维欲望**：牵挂、亲密、好奇、想说、记挂、想逛、行动感、烦、疲惫，继续作为主动行为与语气原因。
3. **短期事件**：只保存事件种类、强度、发生/过期时间和本地规则来源；绝不保存原聊天原文。

同时最多保留 3 个活跃事件；同类事件刷新强度与过期时间而不无限叠加。

### 识别方式：零模型调用

只对用户消息做本地、明确关键词识别，并处理否定和疑问：

| 事件 | 示例明确表达 | 默认时效 | 影响 |
|---|---|---:|---|
| 疲惫 | 好累、累死、困死、好困 | 4 小时 | 疲惫上升、表达更克制 |
| 低落 | 难过、委屈、想哭 | 6 小时 | valence 下降、温柔陪伴 |
| 烦躁 | 好烦、生气、气死了 | 4 小时 | 烦上升；不激化冲突 |
| 愉快 | 好开心、好高兴、兴奋 | 2 小时 | valence / arousal 上升 |
| 不舒服 | 不舒服、难受、疼、头疼 | 4 小时 | 记挂上升、减少打扰 |
| 亲密 | 想你、想抱抱、好喜欢你 | 2 小时 | 亲密与牵挂上升 |

例如“我不难过”“你难过吗”“难过这个词怎么读”不产生事件。规则采用小词表与否定/疑问窗口，不分析隐含情绪。

Daddy 自己的回复不判断用户情绪，只进行轻量状态结算：回复完成后降低“想说”、略增疲惫；含有明显安抚/共同活动结果时只结算 Daddy 自己的沉浸或亲密状态。

### 对话与缓存

情绪天气只在活跃事件或需要的底色变化时产生一段极短、自然语言的动态提示，位置固定为：

```text
固定人设 / 世界书 / 管理记忆 / 工具与插件说明
→ Supabase 临时召回
→ 连续性、健康提示
→ 情绪天气与九维的极短动态提示
→ 当前窗口聊天历史
→ 本轮用户消息
```

它处在稳定前缀之后、聊天记录之前；不会改变人设、工具说明或世界书的缓存前缀。动态事件改变时，仅影响之后的一小段末端缓存。

负面事件的固定陪伴规则为：先温柔陪着、回复相对简短、少讲道理；只有用户直接提出“怎么办/帮我分析/给建议”等请求时才转为建议模式。

### 主动消息

- 低落、疲惫与不舒服时优先安静，若达到既有主动阈值仅允许一句轻柔关心。
- 愉快、亲密与共同活动可略提高自然分享的倾向，但仍受现有冷却、时间、夜间守望、重复抑制与主窗口规则约束。
- 情绪天气不创建第二套定时器，不绕过现有主动消息仲裁。

### UI

九维面板下新增“当前情绪天气”：

- 当前底色（平稳 / 轻快 / 安静 / 烦躁等）；
- 最多三条活跃短期事件、剩余时长和规则来源；
- 当前注入给 Daddy 的简短状态预览；
- 单条清除与“清除全部短期事件”。

面板仅查看与手动清除，不允许直接把数值伪造为某种情绪。

### 验收

- 用户在窗口 A 说“我好累”，窗口 B 的 Daddy 也收到温柔、少讲道理的短提示。
- 否定/疑问句不误触发事件。
- 活跃事件到期后自动消失；不写入 Ombre 或 Supabase。
- 开启后不会增加模型调用；固定人设、工具与世界书的缓存前缀不变。

# 九维欲望状态面板设计

## 目标

让用户在 Daddy 的“主动消息与情绪”设置页中，看见九维欲望系统的当前本地状态；不允许手动编辑，不增加模型调用或 token 消耗，也不改变既有的唤醒决策。

## 体验

“情绪与九维欲望”卡片保持现有开关。开关下方新增“现在的状态”面板：

- 依次展示：想你、亲密、好奇、想说、记挂、想逛、想动手、烦、累（闸门）。
- 每项显示 0–100 的整数、名称与水平进度条。
- “想你”和“累（闸门）”显示简短含义，说明前者会随独处累积、后者偏高时 Daddy 会收敛。
- 面板标注“本地计算 · 不耗 token”，强调数值是状态线索，不是命令或台词。

## 数据与刷新

面板读取 `CompanionMoodSetting.desireState`，并在渲染时调用现有 `evolveCompanionDesire` 计算从最后一次持久化到当前时刻的自然变化。这样页面展示的值与下一次统一唤醒仲裁所依据的值一致，但只读不写回设置。

页面进入、重新组合或设置数据更新时都会重新计算；不建立定时器，不在后台持续刷新。

## 边界

- 不提供任何滑块、重置或手动编辑入口。
- 不改变 `WakeCoordinator` 的阈值、权重或九维演化规则。
- 关闭“九维欲望”时，隐藏状态面板；重新打开时按现有持久化状态展示。
- 不向模型提示词、Ombre、Supabase 或其他服务写入这些数值。

## 测试

- 为展示值转换增加单元测试：0、1、0.5 分别映射为 0、100、50。
- 验证状态面板条目固定为九项，且“累（闸门）”保留专用标签。
- 运行对应 JVM 单元测试与 `assembleCompanion` 构建，确认不会影响可覆盖更新的 companion APK。

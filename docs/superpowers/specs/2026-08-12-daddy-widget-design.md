# Daddy 桌面小组件设计

## 目标

为 Daddy 增加原生 Android 桌面小组件入口，让用户在桌面看到 Daddy 当前状态，不额外调用模型、不增加聊天 token。

## 范围

- 支持 2×2、2×4、4×4 三种尺寸。
- 黑粉色状态卡风格。
- 点击小组件进入 Daddy 主聊天页。
- 2×2 / 2×4 显示：情绪、牵挂或欲望重点、一句短话。
- 4×4 显示：情绪、时间、日期、天气占位/缓存、最近一次正常回复、步数。
- Daddy 小屋加入“小组件设置”，允许启用状态显示并上传一张公用背景图。
- 不在小组件刷新时调用模型。

## 架构

使用 Android 原生 AppWidget + RemoteViews 实现，避免新增 Glance/Compose Widget 依赖。小组件数据由本地 DataStore、情绪引擎状态、连续性状态卡、健康缓存组合而成。背景图路径保存在 Daddy 小屋设置中，并跟随现有本地备份。

## 数据策略

- 情绪：读取 `CompanionMoodSetting` 演化后的状态。
- 欲望重点：使用当前最高的本地状态轴生成一句中文标签。
- 最近回复：从本地聊天数据库中找最近一条 assistant 正常文本回复；若读取成本或接口不稳定，则 v1 使用状态卡/默认短句兜底。
- 步数：读取 Gadgetbridge 已有健康读取逻辑的今日步数；失败时显示“步数待同步”。
- 天气：v1 不主动联网；显示“天气待接入”或后续接入已有天气插件缓存。

## 错误处理

- 任一数据源失败时不崩溃，显示默认文案。
- 背景图缺失或无法解码时回退黑粉渐变。
- 小组件刷新失败只记录日志，不影响 App 启动。

## 验证

- Kotlin 编译通过。
- Debug APK 构建通过。
- 安装后系统小组件列表出现 Daddy 的 2×2、2×4、4×4 小组件。

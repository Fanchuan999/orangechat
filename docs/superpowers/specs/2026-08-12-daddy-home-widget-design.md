# Daddy 桌面小组件与聊天图片管理设计

## 目标

为 Daddy 提供不需要打开应用的桌面陪伴入口，并修正聊天图片管理页缺少缩略图、筛选标签拥挤的问题。小组件只读取本地状态；不触发模型、不产生 API token。

## 范围

### 小组件

- 在 Daddy 小屋新增「桌面小组件」入口与外观设置。
- 支持 Android 原生 `AppWidgetProvider` / `RemoteViews` 的 2×2、2×4、4×4 三种尺寸。
- 三种尺寸点击整张卡片均打开主动消息设置中的主聊天窗口；主窗口未设置时打开 Daddy 首页。
- 所有尺寸使用黑色、粉色文字与半透明黑色遮罩。用户可在小屋上传一张共用背景图；未设置时使用默认黑粉渐变。图像按每个尺寸的中心裁切显示。
- 2×2：情绪天气、最突出的牵挂/欲望、极短一句话。
- 2×4：与 2×2 相同，但容纳更长的短句和更完整的欲望标签。
- 4×4：情绪天气、日期与时间、天气、今日步数、最近一次正常 AI 回复（标作「Daddy 的心声」）。

### 数据和刷新

- 情绪与九维欲望读取 `CompanionMoodSetting`；突出项取当前值最高的有效维度。
- 最近正常回复从已设主聊天窗读取最后一条普通 assistant 文本；忽略工具结果、推送消息和空文本。
- 步数复用 Gadgetbridge 数据读取逻辑；无法读取时显示「步数暂不可用」，不阻塞其他字段。
- 天气使用已有高德 Web 服务 Key 和当前位置。每小时通过 WorkManager 更新一次并缓存最后成功结果和更新时间；离线或定位/Key 不可用时显示缓存，若无缓存则显示「天气待更新」。不调用 AI。
- 聊天消息、情绪状态、用户改小组件背景图或主窗口变化后，应用内主动请求一次小组件刷新；桌面定时刷新只更新时间/天气/步数等本地数据。

### 小屋入口

- 小屋新增「桌面小组件」卡片：显示当前背景缩略说明、上传/移除背景图、天气更新时间、前往系统桌面添加小组件的简短指引。
- 背景图保存到 Daddy 管理的本地文件区，设置中只保存 URI；备份仍按现有 Daddy 设置/文件备份逻辑处理。

### 聊天图片管理修复

- 图片列表每行显示可见缩略图、文件名、大小和日期，加载失败时显示固定占位图。
- 保留现有安全清理/永久删除、选择、全选、时间筛选和二次确认逻辑。
- 时间筛选使用可换行布局；「3个月–1年」和「1年以上」可自然排到第二行，不压缩文字。

## 边界与失败处理

- 小组件不显示聊天图片、健康详细数据或系统工具调用内容，避免桌面泄露过多隐私。
- 背景图不存在或不可读时自动回退黑粉渐变。
- 高德请求失败不会清空旧天气；每次失败仅记录日志并等待下一个小时重试。
- 小组件更新只读数据库和本地文件；不写聊天消息、不改变九维数值。

## 验证

- 单元测试：尺寸内容选择、最近正常回复过滤、缺失主窗口/天气/步数的降级状态、背景图回退。
- 设备验证：添加 2×2、2×4、4×4，上传背景后分别检查裁切和文字可读性；点击进入主聊天窗；断网后确认缓存天气仍展示。
- 图片管理 UI 验证：含多张不同日期图片时确认缩略图、两行筛选和删除选择均可用。
